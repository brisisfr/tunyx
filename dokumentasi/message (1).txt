🎵 PROJECT ACTION PLAN & TASK DIVISIONS

A. DESIGN (UI/UX)
1. Style guide: Neon accents on dark, fonts, UI elements, glow rules
2. Wireframes for all key screens
3. High-fidelity Figma screens matching style guide
4. Visualizer concept sketch (bars/ring/waveform style match)
5. Clickable Figma prototype for professor demo
• Screens: Login/Register, Library, Now Playing (Big Visualizer), Playlists List, Playlist Detail, Upload Form + Persistent Bottom Player Bar

B. FRONTEND BUILD
1. SPA Shell: single `index.php`, fixed bottom player, JS view swapping
2. Player logic: play/pause, seek, volume, track switching, queue
3. Visualizer prototype (standalone, hardcoded MP3 for Week 1)
4. UI Screens built from Figma & wired to API endpoints
5. Audio Integration: Hook visualizer to real player (handle AudioContext resume)
6. Polish: Animations, transitions, loading states

C. DATABASE
1. Schema: Create 7 tables, FKs, unique constraints
2. Seeding: Add test users, artists, songs
3. Queries: Draft & optimize queries per API endpoint
4. Migrations: Export `.sql` dump (re-export on any schema edit)
5. Documentation: ERD diagram + normalization report

D. PHP BACKEND (JSON APIs)
• Rules: PDO prepared statements, return JSON, clear error handling
• Endpoints:
  - `register.php` / `login.php` / `logout.php` (PHP Sessions + password_hash)
  - `me.php` (Session user status)
  - `upload.php` (Save MP3/cover to `/uploads/`, handle artist/track inserts)
  - `songs.php` (List/search all songs with metadata)
  - `playlists.php` (List user playlists, creation)
  - `playlist_tracks.php` (Get, add, remove, reorder tracks)
  - `like.php` (Toggle song likes)

E. SETUP & ENVIRONMENT
• Config: Raise `upload_max_filesize` & `post_max_size` in `php.ini`
• Storage: Create `/uploads/` with file type validation & strict renaming
• Alignment: Standardize local folder & DB names, use relative paths
• Content: Source 15 royalty-free audio tracks + cover art
• QA: Test full setup on a secondary laptop before final demo

F. REPORT & PRESENTATION
• DB Report: ERD, table definitions, normalization, sample queries
• UI/UX Report: Style guide breakdown, design rationale, Figma screenshots
• Deck: Presentation slides + backup screen recording of full demo
